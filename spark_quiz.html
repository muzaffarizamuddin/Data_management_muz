Module 04: Spark Ecosystem

Apache Spark Practice Quiz

Test your knowledge on core components, architecture, RDDs, DataFrames, Spark SQL, and deployment configurations.

Score: 0 / 30 answered correctly

1. How does spark.apache.org officially define Apache Spark?

Explanation: Spark is an open-source, multi-language processing engine capable of running data engineering and data science workloads on localized hosts or distributed clusters.

2. Compared to disk-bound frameworks like Pig or Hive, what type of tasks does Apache Spark make easier to execute?

Explanation: Spark's functional design enables advanced computational pipelines including machine learning, graph theory execution, data mining, and real-time streaming workflows.

3. In the architectural topology of a Spark cluster, what component holds the script that controls what happens with the job?

Explanation: The Driver Program hosts the principal workflow execution script and initializes the execution environment controlling active data jobs.

4. Which cluster managers can be utilized by Spark to distribute jobs across an entire cluster of commodity computers?

Explanation: Spark uses cluster resource negotiators like its built-in Standalone Spark manager or Hadoop YARN to balance data processing pipelines across compute nodes.

5. What element inside each distributed cluster Executor is highlighted as the primary key to Spark's exceptional execution performance?

Explanation: Spark is fundamentally a memory-based solution that attempts to preserve as much operational information in RAM cache as possible, circumventing slow disk-bound processing bottleneck loops.

6. How much faster can Apache Spark run programs compared to traditional Hadoop MapReduce when processing in-memory?

Explanation: Spark documentation notes that its in-memory computing architecture can perform up to 100x faster than traditional MapReduce engines.

7. When Spark runs data operations on disk instead of memory, what is its expected speed advantage over Hadoop MapReduce?

Explanation: Even when forced to write intermediate structures out onto flat storage disks, Spark remains up to 10x faster than MapReduce due to advanced execution graphs.

8. What engine model optimizes workflows inside Apache Spark by working backward from the end result to figure out the fastest pathway?

Explanation: Spark uses a DAG (Directed Acyclic Graph) engine to optimize data workflow routines, map dependencies, and trace the most performant pipeline before execution.

9. Which programming languages can be utilized to author functional pipeline code inside Apache Spark?

Explanation: Developers can interface natively with Apache Spark by deploying script files written in Python, Java, or Scala.

10. What does the foundational architectural concept "RDD" stand for within Spark development ecosystems?

Explanation: The Resilient Distributed Dataset (RDD) is the fundamental data abstraction concept representing an immutable, partitioned collection of records processed in parallel.

11. How does an RDD achieve its "Resilient" characteristic for automatic fault recovery?

Explanation: RDDs achieve resilience by recording a graph lineage of historical transformations, allowing any lost data partition to be rebuilt dynamically if a node fails.

12. What does it mean for an RDD to be "Immutable"?

Explanation: Immutability dictates that an RDD's contents cannot be modified; transformations derive new RDDs while preserving the source datasets intact.

13. Which of the following defines the concept of "Lazy Evaluation" in Apache Spark RDD transformations?

Explanation: Lazy evaluation defers physical computation execution until an action is explicitly requested. This allows the DAG optimizer to construct efficient end-to-end plan sequences.

14. When evaluating RDDs versus DataFrames, how do their levels of abstraction differ?

Explanation: RDDs represent low-level collections lacking built-in tabular schemas, whereas DataFrames are structured, high-level abstractions mapping rows and named columns similar to relational tables.

15. What performance optimization component powers Spark DataFrames, making them faster than low-level RDDs?

Explanation: DataFrames achieve superior execution speeds over basic RDDs by routing queries through the built-in Catalyst Optimizer and Tungsten memory layout engine.

16. What structural characteristic differentiates a Spark DataFrame from a basic RDD dataset?

Explanation: RDDs hold generic objects without an explicit structural schema. DataFrames are structured around named columns with explicit types, enabling relational optimization.

17. Which ecosystem component provides real-time ingestion capabilities within the Spark big data framework?

Explanation: Spark Streaming handles continuous high-volume data streams in real time, routing them into the core engine for processing.

18. What specialized library inside the Spark framework is dedicated to machine learning and data mining operations?

Explanation: MLLib is Spark's scalable machine learning library, delivering algorithms for classification, regression, clustering, and collaborative filtering.

19. Which sub-component of the Spark ecosystem provides graph theory algorithms and analysis abstractions?

Explanation: GraphX introduces structured graph computations and specialized network path operations into the core Spark ecosystem.

20. What is the fundamental running environment and execution entry point within Apache Spark created by the driver program?

Explanation: The SparkContext acts as the entry point to the framework's core runtime environment, establishing coordination and link connections to the cluster components.

21. What implicit object handle identifier is instantiated automatically when launching an interactive Spark shell connection?

Explanation: The interactive command shell environments expose the initialized SparkContext master object reference under the pre-configured variable name 'sc'.

22. When reading paths via a SparkContext method, what do triple forward slashes (file:///...) explicitly indicate to the client engine?

Explanation: The prefix string 'file:///' indicates that the source asset path points directly to a file on the local disk system rather than a distributed storage grid.

23. In PySpark RDD scripting, what mechanism is used to parallelize a raw array list across cluster node structures?

Explanation: The `sc.parallelize()` method accepts a local collection array and breaks it apart into partitioned shards across the cluster nodes.

24. Which of the following represents a valid list of RDD operations categorized explicitly as structural 'Transformations'?

Explanation: Transformations include lazy actions such as `map`, `flatmap`, `filter`, and `distinct` which assemble new RDD structures without triggering execution immediately.

25. What code syntax demonstrates a standard transformation mapping values to their squares using an inline Python lambda function?

Explanation: The expression `rdd.map(lambda x: x*x)` applies an anonymous function to every element inside the dataset, squaring its values.

26. Under the Ambari interface configurations console, what change must be committed to restrict verbose script trace output and capture only severe execution failures?

Explanation: Adjusting `log4j.rootCategory` to log `ERROR` instead of `INFO` inside the spark2-log4j-properties panel silences noisy processing alerts on the terminal console.

27. What terminal command resets the Ambari administrator login password from a secure PuTTY shell instance?

Explanation: Executing `ambari-admin-password-reset` under root terminal privileges restarts the administrative access configuration properties.

28. Which DataFrame API command allows developers to compute average calculations grouped by field categories?

Explanation: DataFrames leverage `groupBy()` combined with downstream aggregate functions like `.mean()` to compute summary analytics.

29. In PySpark, which entry point object must be initiated to execute SQL queries directly against structured tables?

Explanation: Initiating a `HiveContext` or `SQLContext` provides the execution pathway required to translate declarative SQL expressions into Spark data processing tasks.

30. When setting up dependencies via terminal commands to run the movie recommendation model bonus tasks with MLLib, what specific library installation instruction is issued?

Explanation: Running linear algebra operations via Spark's MLLib requires installing compatible analytical numerical dependencies using the system command `sudo pip install numpy==1.16`.
